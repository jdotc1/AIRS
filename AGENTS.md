# Contributor publication rules

Before any public push, pull request, tag, release, source export or asset upload,
read and apply docs/PUBLICATION_POLICY.md. Sanitization includes machine-specific
paths and private metadata, not only credentials or packaged binaries.

Do not treat an application-content check as repository/history/metadata clearance.
Reuse accepted evidence only for the exact content and surfaces it covered.
Keep unresolved publication surfaces explicit and do not publish them as clean.

Preserve unrelated work and existing analysis, verification and release gates.
Do not repeat accepted unchanged checks merely to satisfy this policy. Inspect
new or changed surfaces and retain a local scope-bound receipt instead.

Before changing analysis behavior, read START_HERE.md, docs/ANALYSIS_CONTRACT.md
and docs/VERIFICATION.md. Preserve conservative unknown handling, exact image
identity and independent review of semantic changes.
