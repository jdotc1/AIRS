# Porting imported-callee attribution to MacScope

This note covers AIRS stub attribution, imported declaration syntax and GOT-loaded calls. A consumer needs its own Mach-O reader and equivalent bounded contracts; no AIRS code import is required. AIRS acceptance does not establish MacScope compatibility. This is attribution only. Nothing says a callee throws or returns at runtime. There is no ABI admission, outcome witness, claim about which library dyld binds, or runtime or real-app qualification. The GOT profile is engine-only in AIRS.

## Required adapters

Supply immutable, parser-admitted ordinary `arm64` slice bytes, `cpu_subtype` in `(0, 1)`, `sections`, `functions` and `slice_offset`. Preserve virtual addresses, image base, slice offsets and container offsets. Both attribution readers reread load commands and require raw section metadata to equal admitted metadata (`src/airs/macho_stubs.py`, `src/airs/macho_got.py`). Supply executable mappings, exact function bounds, defined-symbol values, direct branch destinations and data-in-code ranges for the GOT entry screen.

Stub inputs are `LC_SYMTAB`, `LC_DYSYMTAB`, undefined-symbol bounds, nlist records, string bytes, and section `reserved1`, `reserved2`, `nreloc`, address, size, offset and flags. Require a `__TEXT` `S_SYMBOL_STUBS` section without relocations, `STUB_SIZE = 12`, nonempty whole entries and a 4-byte-aligned address. Require exactly `ADRP x16; LDR x16, [x16, #imm]; BR x16`. The loaded 8-byte slot must be aligned in exactly one valid lazy or non-lazy pointer section. The stub and pointer indirect entries must name the same undefined external nlist index. Reject local/absolute entries, debugging symbols, nonzero section/value and invalid names. Preserve both indirect offsets, nlist offset and word offsets. Direct `BL`, or an outgoing `B`, reaches this path only when its target is not a function start.

GOT inputs also include `LC_DYLD_CHAINED_FIXUPS`, segment memory/file mappings, dylib order and paths, namespace flags and classic-bind presence. Require `S_NON_LAZY_SYMBOL_POINTERS`. Source A supplies the indirect entry and undefined external nlist. Source B must reach the slot by walking its page chain and decode its import entry. A raw slot qword alone is insufficient. Accept only plain imports without addends, uncompressed symbols and pointer formats 2 and 6. `_PAGE_SIZES` is `(0x1000, 0x4000)`; `_MAX_LIBRARY_ORDINAL` is `0xF0`. `segment_offset` must equal segment address minus image base. Compare exact name bytes, reject special ordinals, check ordinal ranges, then ordinal equality, weak-flag equality and library path. There is no fallback or tie-break. Classic binding is unsupported.

A GOT candidate needs plain `BLR Xn`, a 64-bit unsigned-offset `LDR Xn, [Xb, #imm]` and an `ADRP` defining the base. Each gap admits only `NOP`, register `MOV`, `MOVZ`/`MOVN`/`MOVK`, or non-flag-setting immediate `ADD`/`SUB`, without writing the tracked register. Reject entry destinations after the `ADRP` through the `BLR`, section crossings and data-in-code. The conditional-branch screen is `w & 0xff000000 == 0x54000000`, covering `B.cond` and `BC.cond`. Computed branches, jump tables, exception landing pads and runtime patching are invisible to this syntactic screen.

## Pure interfaces and negotiation

Reproduce the contracts of `attribute_import_stubs(image, *, limits=...)`, `attribute_got_bindings(image, *, limits=...)`, `GotTable.classify(function, call_pc)` and `parse_import_declaration(symbol, *, limits=...)`. These names describe AIRS interfaces, not a required implementation language. Preserve check order, provenance, completeness and typed declines. `name_offset` is a slice file offset to the name; `chain_step` starts at 0 within the page walk.

Exact profile/report pairs are `broad-imports-v1` / `swift-broad-error-flow-imports-v1` and `broad-imports-got-v1` / `swift-broad-error-flow-imports-got-v1` (`src/airs/swift_broad_profiles.py`). Stub binding is `arm64-import-stub-double-binding-v1`; its row is `swift-broad-import-callsite-v1`. Declaration syntax is `swift-import-declaration-syntax-v1`. GOT binding is `arm64-got-blr-two-source-binding-v1`, chained decoding is `macho-chained-fixups-64-bind-v1`, the window is `adrp-ldr-blr-straight-line-window-v1`, and its row is `swift-broad-got-callsite-v1`. Shared pipeline identities remain `swift-outcome-witness-v2` and `swift-outcome-validation-v2`; imported rows carry neither result.

Negotiate exact identities, never prefixes or version ranges. A consumer needs to retain unknown or mismatched pairs as unsupported raw evidence. Unknown declaration syntax must carry no throwing interpretation. AIRS refuses unknown stub models within its admitted imports pair. AIRS native admission covers only the stub pair here; its recorded-word arithmetic is report consistency, without source-byte rereading or section-containment proof (`docs/MODEL_ADMISSION_REGISTRY.md`, `docs/NATIVE_BROAD_RESULTS.md`).

The closed declaration grammar admits plain functions, struct instance/static methods, metadata accessors, initializers and allocating initializers. It supports literal/Swift/Objective-C modules, nominal/supported extension contexts, bounded substitutions, optional/array types, parameter tuples, `Any`, shared and variadic parameters. Only whole-symbol consumption without an entity-level throws marker permits skipping. Metadata accessors use exact `Ma`; an identifier's `K` proves nothing. `rethrows` remains throwing syntax. `throws(Never)` and Never-returning functions may have plain forms. Every accessor declines; absent effects do not prove it non-throwing. Class/enum methods, explicit generic signatures and word-origin module identifiers decline. A generic parent can be invisible in the symbol. Declines retain no partial identity.

Declaration reasons are `unsupported_production`, `async_context`, `typed_throws`, `closure_type`, `thunk_or_specialization`, `generic_requirements`, `protocol_context`, `unknown_substitution`, `unicode_identifier`, `word_substitution`, `unconsumed_suffix`, `invalid_grammar`, `invalid_input` and `resource_limit` (`src/airs/swift_declaration_profiles.py`, used by `src/airs/swift_import_declarations.py`). First encountered unsupported syntax can determine the reason.

Stub table refusals are `macho_header`, `load_command_limit`, `section_limit`, `raw_section_metadata_mismatch`, `indirect_symbol_table_missing`, `indirect_symbol_limit`, `indirect_symbol_table_extent`, `stub_limit` and `stub_work_limit`. Section/entry declines are `stub_section_segment`, `stub_section_relocations`, `stub_size_unsupported`, `stub_section_extent`, `stub_indirect_range`, `stub_entry_misaligned`, `stub_instruction_pattern`, `stub_pointer_unmapped`, `stub_pointer_section_invalid`, `stub_pointer_binding_mismatch`, `indirect_symbol_local_or_absolute`, `indirect_symbol_index_range`, `indirect_symbol_not_undefined_range`, `imported_symbol_not_undefined_external` and `imported_symbol_name` (`src/airs/macho_stubs.py`).

GOT table refusals share the header/command/section/indirect reasons above and add `got_slot_limit`, `got_entry_screen_limit`, `got_data_in_code_limit`, `got_work_limit`. Image declines are `chained_fixups_absent`, `chained_fixups_duplicate`, `chained_fixups_extent`, `binding_encoding_ambiguous`, `binding_namespace_flat`, `chained_fixups_version`, `chained_header_layout`, `chained_imports_format_unsupported`, `chained_symbols_compressed`, `chained_imports_limit`, `chained_starts_layout`, `binding_library_table_limit`.
GOT source A uses the shared indirect/nlist/name declines. Source B uses `chained_slot_not_covered`, `chained_segment_record_extent`, `chained_page_size_unsupported`, `chained_pointer_format_unsupported`, `chained_segment_offset_mismatch`, `chained_page_start_multi`, `chained_chain_malformed`, `chained_pointer_reserved_bits`, `chained_import_ordinal_range`, `chained_slot_not_member`, `chained_slot_rebase`, `chained_bind_addend_nonzero`, `chained_import_name`.
Agreement/mapping declines are `binding_name_mismatch`, `binding_library_ordinal_special`, `binding_library_ordinal_range`, `binding_library_mismatch`, `binding_weak_mismatch`, `binding_library_name`, `got_slot_unmapped`. Window declines are `got_base_not_adrp`, `got_window_gap_limit`, `got_window_outside_function`, `got_window_incoming_edge`, `got_window_symbol_entry`, `got_window_data_in_code`, `got_slot_unmapped`, `got_slot_section_kind`, `got_slot_section_invalid`. A candidate whose slot was declined when the table was built carries that slot's image, source A, source B or agreement reason instead, so `got_decline_counts` can hold any of those reasons (`src/airs/macho_got.py`).

Non-Swift imports and admitted non-throwing declarations leave the call rows. Other Swift imports remain `unresolved` with `imported_callee_abi_unqualified`, declaration status `syntax_admitted` or `syntax_unresolved`, and empty `candidate`/`validation`. GOT rows use `call_kind: blr_got`. `call_return_proven` and `syntactic_call_target_admitted` are false; `import_attribution_admitted` is true. A missing load shape stays on the earlier path. A declined GOT candidate is counted and retains that earlier row.

## Budgets and acceptance risks

`StubLimits` defaults are `max_load_commands=4096`, `max_sections=4096`, `max_stubs=65536`, `max_indirect_symbols=1_048_576`, `max_symbol_bytes=4096`, `max_work=8_000_000`. `GotLimits` shares the command, section, indirect and name caps; it adds `max_got_slots=1_048_576`, `max_chained_imports=1_048_576`, `max_chain_members=4_000_000`, `max_window_gap=3`, `max_screen_words=4_000_000`, `max_data_in_code_entries=65536`, `max_work=16_000_000`. Stub/slot/screen counts are bounded before decoding. Chain-member exhaustion uses `got_work_limit`. An incomplete table attributes nothing and clears `call_details_complete`; stub incompleteness clears `import_stubs_complete`, GOT incompleteness clears `got_bindings_complete`. An image-level chained failure declines every valid slot and skips source A. A malformed page declines every slot on that page.

`ParseLimits` defaults are `max_symbol_length=4096`, `max_identifier_length=256`, `max_context_depth=16`, `max_nodes=256`, `max_substitutions=128`, `max_parameters=64`, `max_type_depth=16`, `max_generic_parameters=32` (`src/airs/swift_declaration_profiles.py`). Preserve actual charging and production rules, not just the fields. `_MAX_IDENTITY_VALUE_DEPTH` permits 27 levels below the identity, from `_NATIVE_NESTING_LIMIT=32` and `_IDENTITY_REPORT_LEVEL=5`; deeper values decline `resource_limit`.

Both profiles use `IMPORTS_BROAD_LIMITS=EXTENDED_BROAD_LIMITS`: `max_file_bytes=8*1024*1024`, `max_functions=9216`, `max_instructions_per_function=262144`, `max_total_instructions=2097152`, `max_observations_per_function=256`, `max_total_evidence=8192`. Preserve `REPORT_BYTES=16*1024*1024`, `AGGREGATE_WORK=512*1024*1024`, `CALLSITE_WORK_RESERVATION=2_000_000`, `ABI_WORK_RESERVATION=2_032_768`, witness-work reservation and encoded-row charging (`src/airs/swift_broad_flow.py`). Output reserves 65536 bytes and is also bounded by `max_aggregate_bytes`. `got.work` enters `analysis_work`. Stub `work_steps` is `16+len(stub.symbol)`; GOT adds the number of window words. Selection precedes omission; aggregate work, row caps and output exhaustion increase `omitted_calls` and clear detail/witness completeness, without making unresolved calls eligible.

Preserve `import_stub_model`, `import_stubs_complete`, `import_stub_reason`, `import_stub_counts`; the latter contains `attributed_stubs`, `declined_stubs`, `invalid_stub_sections`, `selected_import_calls`, `non_throwing_swift_import_calls`, `non_swift_import_calls`, `declined_stub_calls`. GOT adds `got_binding_model`, `chained_fixups_model`, `got_window_model`, `got_bindings_complete`, `got_binding_reason`, `chained_fixups_status`, `got_counts`, `got_decline_counts`, `got_slot_decline_counts`. Status is `decoded`, an image reason, or `not_decoded` for an incomplete table; the sentinel does not mean no bytes were read. Limitations are `imported_callees_attribution_only`, `got_callees_attribution_only` and `got_window_entry_screen_syntactic`.

Acceptance vectors are retained in `fixtures/swift-error-flow/broad-imports/`: `OwnedImports.swift`, `OwnedImports.macho`, `README.md`, `expected.json`, `expected-got.json`. The first expectation's top-level keys are `source`, `binary`, `compiler`, `flags`, `binary_sha256`, `chained_fixups`, `derivation`, `stub_section`, `pointer_sections`, `stubs`, `stub_calls`, `import_declaration_expectations`. The GOT expectation's are `binary`, `binary_sha256`, `model`, `profile`, `derivation`, `image_base`, `symbol_tables`, `segments`, `got_section`, `dylibs`, `chained_fixups`, `got_slots`, `branch_sites`, `expected_counts`, `expected_decline_counts`. These are Apple-tool-derived expectations, not execution evidence.

The recorded stub vector has 29 attributed stubs and 54 stub calls: 27 Swift and 27 runtime calls counted as non-Swift. Its 19 Swift symbols split into 10 non-throwing, 1 throwing and 8 declined; 27 sites yield 12 selected rows and 15 skips. All 7 demangled-throws sites remain rows. The GOT vector records `got_slots=35`, `agreeing_got_slots=35`, `declined_got_slots=0`, `blr_instructions=7`, `got_candidates=7`, `attributed_got_calls=3`, `declined_got_calls=4`, `selected_got_calls=0`, `non_throwing_swift_got_calls=0`, `non_swift_got_calls=3`. Four metadata-based loads decline `got_base_not_adrp`; three `___chkstk_darwin` rows leave the earlier result. `BR x2` is untouched. There is no compiler-produced Swift GOT row in this fixture.

`tests/test_swift_broad_imports_fixture.py` binds stub expectations to selection. `tests/test_macho_got.py` supplies hand-built positives, refusal order and boundary mutations. `tests/test_swift_broad_got.py` covers Swift GOT rows, skips, retained earlier rows, caps, isolation and fixture counts. `tests/test_swift_broad_native_parity.py` pins native pair/model/reason/count literals and explicitly names the engine-only GOT profile. Recorded syntax evidence includes 494 source-truth symbols (101 non-throwing, 39 throwing, 354 declined), 675 production probes (194 admitted), a 1,999-string differential (0 disagreements; 201 admitted), and a generated-input check of 3,816 inputs: 3,800 strings (660 non-throwing, 178 throwing, 2,962 declined) and 16 inputs that were not ordinary strings, counted in the total only. The differential and generated check predate the word-origin module and nesting restrictions and were not repeated. Word-substituted modules were absent from the differential. Fixture source effects were not separately verified against SDK source. `@_silgen_name` can conceal throwing or async behavior behind plain syntax; that hazard remains.

Coverage is bounded (`docs/SWIFT_BROAD_IMPORTS_PROFILE.md`, `docs/SWIFT_IMPORT_GOT_ATTRIBUTION.md`). Stub `macho_header` and `indirect_symbol_table_extent` are parser-unreachable; the raw-name mismatch is reached locally but full flow refuses it earlier as `section_name_encoding`. GOT tests reach the non-ASCII segment-name cause of `macho_header`; other header/command/extent/duplicate/cursor/unbacked-executable causes and both indirect-extent sites are parser-refused. `got_window_data_in_code` is untested because admitted functions in affected sections are excluded. The function-start cause of `got_window_symbol_entry`, slot-level `got_slot_unmapped`, and command-size cause of `chained_fixups_extent` are untested under parser constraints. A section edge strictly inside a function is prevented; a coincident section/function edge is tested. Absent/duplicate `__TEXT` is parser-refused. The reachable nonzero-`__TEXT`-file-offset cause of `chained_starts_layout` is untested.

The recorded earlier-profile comparisons found unchanged reports; they do not widen admission. Native stub acceptance is report consistency only; app launch, real-input acceptance, packaging and distribution were not done for that change. Two linker tables provide internal consistency, not independent runtime proof. Interposition, missing weak imports, flat lookup and patching remain outside the claim. Unknowns remain unresolved and in denominators. A consumer needs independent reader and integration acceptance; these records establish neither general compiler coverage nor MacScope qualification.
