# Security delta review: integration and limits

Independent review identified and prompted corrections for helper signature
capture, acquisition-time presentation, resource refusals, strict and legacy
entitlement coexistence, and related-component correlation. A related finding
now retains the supported group or reports its omission at a resource limit.
Synthetic tests cover these corrections, historical reopening, malformed
references, and cancellation and task settlement.

The native workflow was exercised using synthetic bundles. Those observations
do not establish behavior on real applications or an installed release.
