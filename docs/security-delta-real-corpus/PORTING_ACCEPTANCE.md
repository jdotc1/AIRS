# Independent MacScope qualification prerequisites

AIRS acceptance does not establish MacScope integration acceptance.

Transfer the existing immutable `SecurityDeltaInput`, strict `SecurityDeltaValue`,
source states, exact identities, observations, findings, coverage, versions and
options through the existing AIRSEntitlements boundary. Both analyzer entry points
and `ComponentSecurityDeltaArchive` retain their production contracts. The corpus
harness is test tooling; do not embed acquisition, Apple subprocesses or oracle
filesystem traversal into the pure analyzer.

A host adapter must provide admitted side/inventory/component identities, exact
UTF-8 paths, raw CPU/subtype/header/slice ranges, original retained bytes and
capture availability. A historical document is data, never a live capability.
Explicit host-owned capture must use no-follow reads, freshness checks, cancellation,
current selection/revision ownership and the existing hard ceilings. Requested
architecture must be explicit; this qualification harness currently admits arm64
comparisons only, while retaining and checking other recorded raw slices.

Replay the committed case manifests and owned mutations independently. Acquire
third-party originals legitimately and keep them private. Reuse approved acquisition
receipts; do not turn a serialized receipt into filesystem authority. Independent
recaptures have new inventory/component UUIDs and are outside cross-capture ID
identity guarantees. Determinism applies to identical admitted evidence/options.

Required host gates:

1. Reproduce manifest, source-digest and exact-side admission, including coordinated
   source/report replacement, wrong component, null IDs, Unicode and raw subtype
   counterexamples. Preserve unknown/absent/empty/unavailable distinctions.
2. Reproduce all certain source-fact and rule-trigger checks. Use the independent
   oracle, with raw offsets and provenance; do not compare the host's serializer
   against itself as a substitute for source truth.
3. Reproduce archive export/reimport/rederivation, 17 mutation families, unknown
   legacy attachment retention, version refusal and historical authority rejection.
4. Repeat the 40 owned protocol/raw-data mutations plus targeted repair regressions,
   output/reference/tree/byte limits, cancellation and late-result rejection.
5. Perform native host selection→direction→capture→inspect→export→historical reopen,
   including paged records, exact paths, typed values, visible coverage and source
   bytes. A host UI/state test and visible native acceptance are separate receipts.
6. Run 100 retained-input analyses on a stratified subset; report memory/latency with
   host/toolchain details and distinguish work limits from process RSS.
7. Have independent reviewers challenge the host adapters and native lifecycle.
   AIRS's two reviews do not qualify another host's integration.

Do not assume a MacScope URL scheme, private framework, adapter, accepted component
identity mapping or UI integration exists. No MacScope source was modified. The
current AIRS corpus's bounded unresolved outcomes are acceptance expectations,
not permission for a host to coerce missing evidence to empty or absent. The
external-volume, clean-machine, minimum-OS and actual blocking Security.framework
conditions listed in RESULTS require separate host/environment evidence.

Additional oracle refusal: normalized Python datetime values cannot establish
original DateBits equality. Keep those comparisons unresolved unless a separately
qualified raw date adapter is supplied. Production strict date serialization is
portable and unchanged; this is an independent-oracle fidelity boundary.
