# Larger Swift function-inventory profile

`broad-large-v1` is an explicit, separately identified resource profile for the existing broad structural analysis. It admits up to 9,216 recorded function entries and executable symbols; `broad-v1` remains capped at 8,192. Both retain the 8 MiB image, 16 MiB report, 262,144 scanned-word, 4,096 retained-call, and 512 MiB aggregate algorithmic-work ceilings, together with all separate metadata, ABI, witness and independent replay budgets. A larger inventory does not imply complete analysis: independent metadata admission may refuse, and work or output limits can leave recorded coverage incomplete.

The outer model is `swift-broad-error-flow-large-v1`. It uses the unchanged `broad-v1` candidate/witness and validation semantics; that inner identity does not mean the outer resource profile is broad-v1. The native workflow selects the resource profile explicitly, checks the returned model, preserves source JSON, and treats reopened reports as historical. No call return, runtime execution, source semantics or exclusive handler is established.

Qualification used owned synthetic images at 8,617 and 9,217 function entries, profile routing and model-binding tests, and a large-image call replay whose ABI qualification was deliberately mocked. This checks pipeline plumbing and independently replays the recorded instruction facts; it is not an independent compiler ABI qualification. An independent source reviewer identified and prompted corrections to direct-entry profile defaults and the profile registry. Authentic-case results are reported separately from synthetic qualification.
